# Primordial Skies

*From a single cell to the stars.* A survival, crafting and base-building game: begin as a
cell in a primordial pool, grow into a lake creature, walk ashore, and build a home in a
large diggable world - with friends if you like.

## Download

**[Download the installer (PrimordialSkies-Setup.exe)](https://github.com/CBFISH12/primordial-skies/releases/latest/download/PrimordialSkies-Setup.exe)** - Windows 10/11, 64-bit.

1. Run the installer. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway** (the game isn't code-signed yet).
2. It installs just for you (no admin needed) and adds a Start menu entry.

## Updates

The game checks for updates on its title screen. When a new version is out, click
**Update now** - it downloads and restarts. Your worlds are kept.

## Playing together

Everyone needs the same version. One player hosts (pause menu -> *Host this world*), the
others use **Join Game** on the title screen with the host's address.

## Saves

Your worlds live in `%APPDATA%\Godot\app_userdata\SurvivalCraft` and are kept when you
update or uninstall.
